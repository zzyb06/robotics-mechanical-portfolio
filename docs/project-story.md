# R1 机器人项目设计说明

## 1. 项目定位

项目名称：2026 Robocon「武林探秘」R1 机器人

项目方向：机器人机械结构设计与制造

项目角色：R1 机器人负责人，负责 R1 全部机械系统

项目关联：本 R1 机械系统同时作为国家级大学生创新创业项目“工业场景多模态重载搬运机器人”的实践基础，用于验证轮式重载搬运、末端执行器和自动抬升等机构方案。

项目背景：面向 Robocon 比赛任务设计并制作 R1 机器人，使机器人能够在比赛场地内完成规定动作。机械系统需要在有限空间、时间和材料条件下兼顾运动范围、结构强度、机构可靠性、加工可行性和维护效率。

本项目的核心价值在于完整呈现一套竞赛机器人的机械开发过程：从任务理解和总体布局开始，经过 SolidWorks 建模、零件拆分、工艺选择、加工装配，最终进入整机调试和结构迭代。

## 2. 我的职责

我负责 R1 的全部机械工作，具体包括：

- 参与比赛任务分析和整机机械布局
- 负责底盘、机械臂、抬升机构、传动结构和连接支撑件的机械设计
- 使用 SolidWorks 完成零件、子装配体和整机装配体建模
- 根据零件功能选择铝型材、铝方管、板材和 3D 打印件等结构方案
- 将设计拆分为适合激光切割、钣金折弯和 3D 打印的零件
- 完成结构装配、配合关系检查、干涉检查和现场调整
- 根据调试中发现的问题修改结构并更新模型

## 2.1 项目职责与岗位能力对应

本项目覆盖机械岗位中从设计到落地的完整链路：

- **CAD 与工程表达：**使用 SolidWorks 完成零件、子装配体和整机装配体建模，进行配合关系与干涉检查，并根据制造需求输出二维工程图和 BOM
- **制造与供应商协作：**根据零件受力、精度和形状选择机加工、激光切割、钣金折弯或 3D 打印工艺，对接供应商跟进零部件生产、检验和质量改进
- **末端执行器设计：**围绕比赛任务设计气动夹爪和真空吸盘等末端执行器，分别用于矛杆抓取和 KFS 吸取
- **整机集成与测试：**完成机械装配，并将电机、传感器和线缆集成到结构中，协同进行整机联调、故障排查和结构迭代

## 2.2 比赛任务与机械需求

R1 的比赛任务可以归纳为四个主要动作：

1. 抓取矛杆，并在武馆内与 R2 的矛头完成组装对接。
2. 携带矛杆通过梅林的 R1 过道。
3. 按比赛策略抓取不同高度的 KFS，携带进入对抗区并放入九宫格第一层。
4. 等待 R2 完成第二层摆放后，将 R2 举升约 50-60 cm，为第三层放置创造条件。

这套任务决定了 R1 机械系统需要同时满足以下要求：

- 抓取机构需要适配矛杆，并为与 R2 矛头的组装对接留出稳定的接口和操作空间
- 车体和上层机构需要适应梅林过道的空间限制，避免运动过程中发生干涉
- 执行机构需要覆盖不同高度的 KFS，并在抓取、搬运和放置过程中保持物体稳定
- 举升结构需要在协同阶段将 R2 抬升约 50-60 cm，同时保持结构稳定和动作可控

上述要求构成 R1 机械方案设计、装配调试和结构迭代的主要依据。

## 3. 机械系统拆解

### 3.1 底盘与轮组

底盘承担整机的支撑、移动和各机构安装任务。设计时需要同时考虑轮组布置、车架空间、驱动部件安装、结构刚度和后续维护空间。

当前资料中包含 R1 麦轮轮组、轮组安装件、车架纵梁、横梁、避震安装件和多种加强连接件。底盘结构围绕以下内容进行设计：

- 底盘总体尺寸
- 轮组数量与布置方式
- 车架材料和板材厚度
- 底盘与上层机构的连接方式
- 底盘调试中的结构稳定性和维护便利性

### 3.2 机械臂与执行结构

机械臂负责将执行机构布置到指定工作空间，需要在活动范围、结构刚度、驱动安装和末端接口之间取得平衡。

当前资料中包含机械臂底部、中间板、上层固定件、车架连接件、轴承加强件以及末端连接相关零件。机械臂结构设计重点包括：

- 机械臂需要完成的比赛动作
- 运动自由度和主要转动/移动副
- 关键受力位置
- 轴承、齿轮、齿条或滑轨的选型依据
- 为避免干涉而做的结构调整

### 3.3 抬升与导向结构

抬升机构需要完成稳定的垂直或近似垂直运动，设计中重点关注导向、受力、限位、传动和安装刚度。

当前资料中包含抬升面、抬升面连接件、碳板、铝方管、线性滑轨、滑块、齿条和电推杆安装件等模型。抬升结构围绕抬升行程、导向方式、受力传递和动作限位进行设计。

### 3.4 连接件与快速制造件

比赛机器人需要频繁修改结构，因此连接件不仅要满足强度和定位要求，还要便于加工、更换和现场维护。

本项目使用了铝型材、铝方管、板材和 3D 打印件组合装配。3D 打印件用于快速验证结构、补偿装配关系或制作定制支撑件；板材通过激光切割和钣金折弯形成安装板、加强板和连接件；铝型材与铝方管用于搭建和连接主体框架。

## 4. 设计与制造流程

### 4.1 方案设计

根据比赛任务先确定机器人需要到达的工作空间、动作顺序和机构接口，再进行底盘、机械臂和执行机构的总体布局。这个阶段优先解决机构之间的空间关系和运动可达性。

### 4.2 SolidWorks 建模

先建立关键零件和标准件模型，再按照功能拆分子装配体，最后合并到 R1 总装中。建模过程中需要持续检查零件之间的安装关系、运动空间、紧固件位置和加工可行性。

### 4.3 零件拆分与工艺选择

依据零件的受力、精度、形状和修改频率选择制造方式：

- 适合平面轮廓的零件采用激光切割
- 需要折弯成形的板件采用钣金折弯
- 需要快速修改或定制连接的零件采用 3D 打印
- 主体框架使用铝型材和铝方管装配

### 4.4 装配与调试

加工完成后按照装配关系逐级组装，先验证单个机构，再进行整机联调。调试重点包括运动范围、机构干涉、连接刚度、限位位置和维护便利性。

### 4.5 结构迭代

将调试中发现的问题回溯到模型和装配关系中，修改零件尺寸、安装位置、加强方式或限位方案，再重新加工和验证，形成从模型到实物、再回到模型的迭代闭环。
