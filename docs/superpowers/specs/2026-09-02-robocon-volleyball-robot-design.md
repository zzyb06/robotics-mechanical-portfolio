# 2026 ROBOCON 排球机器人项目页设计

## 目标

在现有 GitHub 作品集中增加一个独立的 2026 ROBOCON 排球机器人项目页，突出用户负责的摆臂击打式发球机构，展示从机械方案、SolidWorks 建模、样机制造到测试优化的完整过程。

## 项目定位

- 项目名称：2026 ROBOCON 排球机器人挑战赛
- 核心模块：摆臂击打式发球机构
- 已确认结构：双 GO 关节电机串联，形成“肩关节—肘关节”式双段摆臂
- 用户职责：发球机构的机械设计、建模、制造、装配、调试和结构优化
- 已确认成果：2026 ROBOCON 排球比赛一等奖
- 项目边界：本项目与 2026 ROBOCON「武林探秘」R1 项目、浙江省工程实践与创新能力大赛“智能+”项目分别记录，不混用项目名称、经历和奖项

## 受众与表达重点

面向机器人机械、机械结构设计和机电一体化方向的实习招聘者。页面优先回答四个问题：

1. 发球机构要完成什么比赛任务
2. 机构由哪些机械模块组成，为什么采用双段摆臂
3. 用户具体负责了哪些设计、制造和调试工作
4. 通过什么测试和迭代验证了机构效果

## 页面结构

在 `docs/volleyball-robot.md` 中使用以下结构：

1. 项目概况与比赛任务
2. 个人职责与工作范围
3. 发球机构总体方案
4. 双 GO 关节电机串联摆臂结构
5. 摆臂击打式发球动作链
6. SolidWorks 建模、加工与装配
7. 样机测试与结构迭代
8. 项目成果、比赛视频和图片证据

在根目录 `README.md` 的项目经历中增加一段简短项目卡片，链接到该项目页；同时把“智能+”项目的描述与排球机器人发球机构彻底分开。

## 公开内容边界

- 只公开 2026 ROBOCON 排球机器人挑战赛及用户实际负责的发球机构
- 可以使用经过筛选的机器人实物图、发球机构局部图和 SolidWorks 截图
- 不上传附件说明书原文件、完整 CAD、工程图、BOM、内部比赛材料或本地路径
- 不把附件说明书中的文档比赛名称写成实际参赛经历
- 不直接采用附件说明书中的发球速度、接触时延、轨迹偏移、拦截率等宣传性或未单独核验的数据
- 未补充真实测试记录前，不写具体发球速度、命中率、重复性或旋转角速度
- 不扩展描述用户没有确认负责的视觉、拦截、通信和算法模块

## 视觉素材策略

- 首选一张排球机器人实物总装图，作为项目页开头的结构概览
- 优先补充一张发球机构近景或 SolidWorks 装配截图，标出双段摆臂、电机、击球端和支撑结构
- 如果没有可公开的近景图，先保留文字说明，不用文档中的防守端流程图代替
- 视频只添加能够证明排球机器人发球动作的公开链接，不复用武林探秘比赛视频

## 验收标准

- README 独立列出 2026 ROBOCON 排球机器人项目，并链接到 `docs/volleyball-robot.md`
- 项目页全程使用“2026 ROBOCON 排球机器人挑战赛”作为项目名称
- 项目页明确写出摆臂击打式、双 GO 关节电机串联和肩关节—肘关节式结构
- 项目页明确写出用户负责发球机构设计、建模、制造、装配、调试和优化
- 项目页写出排球比赛一等奖，但不把其他比赛或奖项混入本项目
- 页面不出现附件文档比赛名称、原始文件名、本地路径和未经核验的性能数据
- 现有作品集结构测试通过，Markdown 无格式错误，更新后的提交推送到 GitHub
