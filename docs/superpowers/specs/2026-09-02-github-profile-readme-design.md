# GitHub 个人主页 README 设计

## 目标

创建一个名为 `zzyb06` 的 GitHub 个人主页仓库，使招聘者进入 GitHub 账号首页时，能够快速了解作者的专业方向、机械工程能力、代表项目、竞赛成果，并进入完整的机器人机械作品集。

## 受众与定位

- 受众：机器人机械、机械结构设计、机电一体化方向的实习招聘者和项目合作人员
- 个人定位：宁波工程学院机器人工程本科生，专业前 30%，专注机器人机械结构设计、SolidWorks 建模、原型制造和整机调试
- 语言：中文为主，保留 SolidWorks、ROS、STM32、BOM 等岗位检索关键词
- 语气：简洁、事实导向、工程求职风格

## 页面结构

个人主页 README 只保留六个信息区块：

1. 一句话身份与求职方向
2. 核心技能：CAD 与图纸、制造工艺、机电集成、控制与测试
3. 精选项目：国家级大学生创新创业项目与 2026 Robocon R1
4. 竞赛成果：用户已确认的 Robocon、工程实践和 TI 杯奖项
5. 作品集入口：链接到 `zzyb06/robotics-mechanical-portfolio`
6. 当前关注方向：机器人机械结构、末端执行器、加工落地与测试迭代

页面不使用装饰性大图、复杂徽章或与求职无关的统计信息，避免影响招聘者快速扫描。

## 内容边界

- 可以公开项目名称、比赛名称、个人职责、已确认奖项和作品集链接
- 不公开 QQ、邮箱、电话等联系方式
- 不公开原始 SolidWorks 文件、STEP、工程图、完整 BOM、内部申报材料和本地路径
- 不把重量、尺寸、动作时间、承载能力或精度等未提供实测证据的数据写成结果
- “国家级大学生创新创业项目”与 R1 的关系表述为：R1 机械系统作为实践基础开展方案验证

## 实现与发布

- 在当前作品集仓库中先维护一份可审阅的主页 README 草稿
- 创建公开 GitHub 仓库 `zzyb06`，仓库根目录只放个人主页 `README.md`
- 将主页仓库链接到现有作品集仓库，不复制原始 CAD 和敏感资料
- 通过 GitHub CLI 验证仓库所有者、公开状态、默认分支和远程提交

## 验收标准

- 访问 `https://github.com/zzyb06` 时能看到个人主页 README
- README 包含个人定位、四类技能、两个核心项目、已确认奖项和作品集链接
- 作品集链接指向 `https://github.com/zzyb06/robotics-mechanical-portfolio`
- 文本中不存在 QQ、邮箱、电话、本地路径、原始 CAD 文件名和未经确认的性能结论
- 主页仓库与本地提交同步，工作区无未提交修改

## 不在本次范围内

- 创建独立的个人网站或 GitHub Pages 页面
- 上传完整 SolidWorks 装配体、零件、工程图或申报书
- 添加联系方式、个人头像和社交媒体账号
- 自动生成 GitHub 统计卡片或动态贡献图
