# 公开范围与发布检查

## 公开原则

本仓库用于求职作品集，只展示能够证明个人能力的项目说明和视觉证据，不公开比赛内部方案和原始设计资料。

## 可以公开

- 项目名称和比赛名称
- 个人职责和参与范围
- 已经确认可以公开的结构原理说明
- 经过筛选的总装截图和机构截图
- 不包含敏感尺寸的局部建模截图
- 已验证的技术栈、加工工艺和项目结果
- 公开的个人 GitHub、邮箱或其他联系方式

## 不公开

- `.SLDASM`、`.SLDPRT`、`.SLDDRW` 等 SolidWorks 原始文件
- STEP、STP、工程图和完整零件清单
- 比赛尚未公开的结构方案、参数和策略
- 团队成员电话、邮箱和其他私人信息
- 申报书、内部会议资料和学校盖章材料
- 未经测试或无法证明来源的性能数据
- 密钥、密码、账号信息和本地路径

## 截图发布前检查

- [ ] 截图中没有显示本地文件路径
- [ ] 截图中没有其他成员的联系方式
- [ ] 截图中没有未公开的比赛策略或内部标记
- [ ] 只展示必要的结构细节，不上传完整可复用设计
- [ ] 图片文件名使用英文和数字，便于 GitHub 正常显示
- [ ] README 中的参数都有测试记录或明确来源
- [ ] 发布前再次确认当前赛季的公开规则

## 本地文件保护

根目录 `.gitignore` 已包含 SolidWorks、STEP、Office、PDF 和压缩包文件规则。即使后续需要提交展示资料，也应只复制经过筛选的 PNG、JPG、GIF 或 MP4 文件到 `assets/` 目录。
