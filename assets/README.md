# 展示素材清单

这个目录只放已经确认可以公开的图片或视频，不放原始 CAD 文件。

## 推荐文件名

```text
r1-overview.png
r1-gripper.png
r1-chassis.png
r1-arm.png
r1-lift-module.png
r1-cad-assembly.png
r1-manufacturing.png
r1-assembly-process.png
r1-demo.mp4
volleyball-robot-overview.jpeg
```

## 补图顺序

1. `r1-overview.png`：R1 整机总装图（已加入）
2. `r1-gripper.png`：气动爪及末端装配展示（已加入）
3. `r1-chassis.png`：纵梁式麦克纳姆轮底盘展示（已加入）
4. `r1-arm.png`：塔吊式机械臂与末端吸盘展示（已加入）
5. `r1-lift-module.png`：抬升承托平台与导向结构展示（已加入）
6. `r1-cad-assembly.png`：SolidWorks 总装截图
7. `r1-manufacturing.png`：激光切割、钣金折弯或 3D 打印件
8. `r1-assembly-process.png`：铝型材、铝方管和实物装配
9. `volleyball-robot-overview.jpeg`：2026 ROBOCON 排球机器人实物总装图，当前用于展示排球机器人整体结构和发球机构安装区域

## 图片要求

- 优先使用清晰的 PNG 或 JPG
- 图片中不要出现本地路径、私人信息或内部文件名
- 一张图尽量只表达一个结构重点
- 每张图在 README 或项目文档中配一段说明
- 视频可先上传到 GitHub Releases、网盘或公开视频平台，再把链接放入 README
